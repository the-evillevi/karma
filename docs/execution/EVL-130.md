# EVL-130 report export checkpoint

The first bounded module generates UTF-8 BOM CSV evidence from explicitly selected local sale, payment, and compensation records. It uses the reviewed compatible adapter to retain captured net cash, tender/change, tips, payment identity, refund allocations, and original actor. Text cells neutralize spreadsheet formulas and CSV delimiters; no PIN, session, roster, customer profile contact, or privileged credential is exported.

Original legacy display dates remain recorded text with blank real-date columns and an explicit warning. ISO UTC facts are rendered in the supplied validated branch time zone. No simulated day offset is converted into a fabricated date; no local sync label is treated as proof of a server receipt. The file is a local sales-evidence export, not a complete backup or verified accounting close.

Only the pure builder is implemented at this checkpoint. Current-role-gated download UI, real checkout timestamp capture, real period/custom date range filters, reconciled dashboard totals and independently reviewed export acceptance remain open. Do not claim a download occurred or publish this as full EVL-130 acceptance.

Three domain regression cases passed for exact net payment/change, branch midnight, original unknown dates, refund identity, source immutability, inconsistent captured amounts, invalid zones, formula escaping and CSV quoting. Scoped TypeScript passed.
