# EVL-158 — responsive POS shell and mobile navigation

## Scope and base

This is an implementation checkpoint on the EVL-158 branch, stacked on the reviewed EVL-156 work and integration commit `5f2fe86`. The integration base contains SalesStation and the four HTML build entries. Work here is limited to the POS shell, navigation, responsive module containers, and viewport regression coverage. SalesStation actions and order state remain owned by the catalog implementation.

The desktop navigation now uses shadcn Sidebar. Below 1024 CSS pixels it becomes a sticky compact bar with a shadcn Sheet containing the same navigation, open-order count, connection and pending-sync state, sync controls, kitchen link, and current-user action. This includes the 768–1023 tablet band in `DESIGN.md`; the sales cart keeps its independent 700px stacking breakpoint. Short landscape sheets scroll to their footer controls. Choosing a navigation item closes the Sheet and returns focus to the menu trigger. Sidebar colors use the values already defined by the Karma semantic tokens in `src/styles.css`.

The POS content column can shrink without widening the document. Module padding contracts at tablet and phone widths, and wide inventory/report tables scroll in their card containers. The cart and module business actions are unchanged.
