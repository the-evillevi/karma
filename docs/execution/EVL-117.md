## Print fixture and repeatable procedure

It exercises narrow receipt width, folio/Mesa consistency, amount alignment, modifiers, notes, Spanish accents, a long line, payment/tip labels, cut/end-of-paper, and a clearly marked no-value test state. The IVA amount is an obvious placeholder: the fixture tests layout only and must not be used as a real receipt or to decide the configured tax amount.

Reproduction: open the HTML fixture on the actual POS host; select the actual configured queue and the station's existing validated paper configuration with its matching driver media setting; use 100%/actual size where the driver supports it; print both pages; record the physical output. The fixture has a 52mm content column that fits 58mm and 80mm stock. Never change the printer's paper width, guides, or media configuration just for the fixture. For Epson TM-T20III, the official guide says an 80mm-to-58mm conversion cannot be reversed after use because of printhead/autocutter wear (pp. 40, 44); any planned physical change requires guidance from a technician familiar with the exact model. A browser preview is not a printer test. Run the procedure separately for the receipt printer and kitchen route, with a witnessed cash-drawer pulse test separately after exact wiring/electrical compatibility is confirmed. Do not pulse unknown hardware. Use the redacted evidence template and manual validation steps in the matrix.
