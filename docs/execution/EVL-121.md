# EVL-121 checkpoint: quick-sale station

## Delivered in this checkpoint

The POS catalog and current-order panel now render through `src/SalesStation.jsx`, with station-specific responsive rules in `src/SalesStation.css`. `PosApp` still owns the demo order draft and existing sale actions. The station keeps product search, category filtering, product availability feedback, modifier/note editing, cart quantity controls, removal, order type and reference, totals, and the existing save/comanda/charge actions.

The product editor validates a proposed line against the reviewed EVL-120 catalog capture rules before it updates the draft. Required selections and active options are checked, a configured default is retained when editing an older demo line that lacks it, and the existing order shape and price calculations remain in place. This adapter is only a demo-runtime guard: it does not replace an immutable production order snapshot or server validation.

Keyboard support includes `/` or Ctrl/Cmd+K to focus search, Up/Down to move between results, Enter in search to open the first result, Escape to close the editor/collapse the mobile cart/clear search, and Alt+Down to open and focus the cart. Native buttons retain their standard keyboard behavior. Search, products, order fields, and cart actions have persistent accessible names; interactive controls have visible focus states and 40–48px hit areas.
